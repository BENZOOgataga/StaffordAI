## Stafford v0.1.0, Windows

This is the first public build of Stafford. It is Windows only for now. macOS and Linux
are written and come in a later release; I develop on Windows and did not want to gate
the first build on switching machines to verify the others. The build is unsigned, so
Windows SmartScreen warns once on first launch and you approve it.

## What Stafford is

Stafford runs Claude Code agents as a team you manage from one window. You hire a
colleague onto a project, send it a message, and see its reply and what it is doing,
with each colleague isolated in its own session so your own Claude Code setup and its
plugins never leak into it.

## What works in this build

- Create a project and hire a colleague onto it, then message it and get the reply in
  the same window.
- A real Claude Code session per colleague, isolated against a Stafford managed config,
  so your global plugins and hooks do not load into it.
- A per colleague conversation that shows both sides, yours and the colleague's.
- A roster with one card per hire, showing working, idle, waiting, and the rest, driven
  by the colleague's own session rather than by reading a terminal.
- An Activity feed and a Transcript per colleague: the Activity feed lists what it did,
  and the Transcript shows its replies and tool calls for the turn.
- Committed work is checkpointed to a branch when the app drains on quit, so a
  colleague's changes are not lost.
- Clean shutdown, so no session is left half torn down.

## Since the rc.1 pre-release

The way Stafford talks to Claude was reworked from the ground up. Messages now send
reliably, including the very first one after you open the app, with no need to resend.

## Install (Windows)

The build is unsigned, so Windows SmartScreen stops it the first time. This is expected
for an unsigned build, not a sign anything is wrong.

1. Download `Stafford-0.1.0-win-x64.zip` from this release.
2. Unzip it. You get a `Stafford-0.1.0-win-x64` folder.
3. Run `Stafford.exe` inside the folder. There is no installer.
4. SmartScreen shows "Windows protected your PC". Click More info, then Run anyway.
5. Stafford starts in the tray and runs there until you open it.

You approve it once, and Windows remembers the choice for that copy.

## Requirements

- Windows 11.
- Claude Code installed, through its native installer.
