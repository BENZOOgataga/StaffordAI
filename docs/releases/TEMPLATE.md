## What's new

One or two plain sentences on what this release is about, for someone scanning the list. Say what a person
can now do that they could not before, not a list of internal changes.

## Features

### A feature, named in plain words

What it does and why it matters, in a sentence or two of prose, not a changelog line. Then the picture that
shows it.

![What the feature looks like](img/<version>/<name>.png)

### Another feature

Same shape: the prose first, then a screenshot if it helps. Only the features worth a person's attention go
here; the smaller merged work shows up in the auto changelog below on its own.

## Bug fixes

Hand-pick the fixes worth calling out, the ones a person felt or asked about. One line each, plain.

- Fixed the thing that did the wrong thing, so now it does the right thing.
- Fixed the other thing.
