## Stafford v0.1.0-rc.1, Windows

This is the first public build of Stafford, a pre-release. It is Windows only for now.
macOS is written and comes in a later release; I develop on Windows and did not want to
gate the first build on switching machines to verify macOS. The build is unsigned, so
Windows SmartScreen warns once on first launch and you approve it.

It is early. There are rough edges, one of which is written up under Known issues below.
I am shipping it so it can be used and so I can hear what breaks. Feedback is welcome.

## What Stafford is

Stafford runs Claude Code agents as a team you manage from one window. You hire a
colleague onto a project, send it a message, and see its reply and what it is doing,
with each colleague isolated in its own session so your own Claude Code setup and its
plugins never leak into it.

## What works in this build

- Hire a colleague onto a project and message it, with the reply in the same window.
- A per colleague conversation, so each colleague keeps its own thread.
- A roster with one card per hire, showing working, idle, waiting, and the rest, from
  Claude Code's own signals rather than from reading a terminal.
- A channel: one timeline across every colleague, with an inline reply on a row.
- Each colleague runs against a Stafford managed config, so your global plugins and
  hooks do not load into it.
- Committed work is checkpointed to a branch when the app drains on quit, so a
  colleague's changes are not lost.
- Clean shutdown, so no session is left half torn down.

## Install (Windows)

The build is unsigned, so Windows SmartScreen stops it the first time. This is expected
for an unsigned build, not a sign anything is wrong.

1. Download `Stafford-0.1.0-rc.1-win-x64.zip` from this release.
2. Unzip it. You get a `Stafford-0.1.0-rc.1-win-x64` folder.
3. Run `Stafford.exe` inside the folder. There is no installer.
4. SmartScreen shows "Windows protected your PC". Click More info, then Run anyway.
5. Stafford starts in the tray and runs there until you open it.

You approve it once, and Windows remembers the choice for that copy.

## Known issues

The first message you send to a colleague right after opening the app sometimes does
not go through. If you send a message and get no response, send it again and it will
work. Every message after the first is fine. This is a startup timing issue in how
Stafford talks to Claude, and the permanent fix is the headless engine rework already
on the roadmap.

## Requirements

- Windows 11.
- Claude Code installed, through its native installer.
